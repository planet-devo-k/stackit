# 11장. 재귀적으로 작성하는 법
## 11-1 재귀 카테고리: 반복 실행
- 재귀를 사용하는 이유는 여러가지가 있는데, 결국 본질적으로는 반복적인 작업을 간단하게 작성할 수 있기 때문
- 문제를 잘들여다보면 본질적으로 같은 문제인 경우가 있는데, 그럴때 효과적이라는 생각이 들었다.
- 몇가지의 재귀의 올바른 사용법 중, 반복 실행을 해야하는 문제가 직관적으로 이해가 잘되는 편


## 11-2 재귀 카테고리: 계산
- 상위 문제를 하위 문제로 나누어서 풀 수 있을 때도 재귀가 효과적이다.
- 상향식과 하향식의 방법이 있다.
- 하향식으로 풀려면 재귀를 써야만 한다고 한다.
  - 으음 그런가? 하향식이라는 말 자체가 하위문제를 먼저 풀고 그 값을 이용해 상위 문제를 푸는거고.. 그렇다면 안쪽 깊숙히 들어가서 기저조건을 만족시켜야한다는 전제조건이 있긴할테니 그럴수있겠다.


## 11-3 하향식 재귀 : 새로운 사고방식
- 하향식 재귀는 문제를 해결하는 새로운 사고 전략을 제공한다는 점에서 의미가 있다고 한다.
- 문제를 풀때, 이건 하향식에서 구체화 된다고 생각하고 일단 작성하는 추상화가 들어가는 듯 하다.
- 하긴 처음 배웠을때 이해가 정말 어려웠던 기억이 난다.


## 11-4 계단 문제
- 유명한 계단 문제
- 계단을 오르는 방법이 1, 2, 3 칸을 한번에 오르는 방법이 있다고 했을때, 300개의 계단이 있다면 총 경로가 몇개일까? 와 같은 문제.
- 300개의 계단을 오르는 방법은 299, 298, 297개의 계단을 오르는 방법의 합이고, 299는 298, 297, 296개의 계단을 오르는 합이다 와 같이 정의할 수 있음.
- 이와 같은 방법으로 간단하게 풀 수 있다는 점이 하향식 재귀의 장점이다.
