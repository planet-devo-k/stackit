# 1장. 자료 구조가 중요한 까닭
## 1.1 자료구조
- 데이터를 어떻게 조직하느냐에 따라서 코드의 실행 속도에는 영향이 갈수밖에없다.
- 데이터를 조직하는 방법이 자료구조이다.


## 1.2 배열: 기초 자료 구조
- 배열을 포함한 자료구조의 성능은 읽기, 검색, 삽입, 삭제 4가지 동작으로 성능을 측정한다.


## 1.3 속도 측정
- 속도는 시간복잡도로 측정한다.

## 1.4 읽기
- 배열의 인덱스만 주어진다면, 메모리 공간에서 주소값을 통해 한번에 접근하여 어떤 값이 메모리공간에 저장되어있는지는 바로 찾을 수 있다.
- 즉, 배열에서 읽기 연산은 매우 빠르다

## 1.5 검색
- 어떤 값이 있는지 찾으려면 결국은 모든 배열을 순회해야하므로 읽기보다는 덜 효율적이다.

## 1.6 삽입
- 맨 끝에 넣는 삽입 동작은 넣기만 하면 되니 매우 빠르지만
- 중간에 넣는다면? 뒤의 원소는 다 한칸씩 밀어야하므로 느릴수밖에없다.

## 1.7 삭제
- 삭제도 중간 원소를 삭제한다면 한칸씩 당겨야하므로 느리다.

## 1.8 집합: 단 하나의 규칙으로 효율성이 달라진다.
- 집합은 중복 데이터가 없고 배열기반의 `Set`을 여기에서는 말하고 있음.
- 그래서 삽입 시, 중복데이터가 없어야 하므로 검색이 우선되는데 배열기반이면.. 결국 전체를 탐색해야한다.
- 집합의 끝에 삽입을 하더라도 전체를 탐색해야하므로 여전히 느림.

## 1.9 마무리
- 자료구조의 성능 측정은 연산에 필요한 단계 수를 구하는 것이 핵심이다.
