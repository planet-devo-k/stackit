# 3장. 빅 오 표기법
## 3.1 빅 오: 원소가N개일 때 몇 단계가 필요할까?
- 핵심 질문은 데이터 원소가 N개일 때 알고리즘에 몇 단계가 필요할까이다.
- 그리고 O(N)은 알고리즘에 N단계가 필요하다는 의미이다.

## 3.2 빅 오의 본질
- 데이터가 몇 개든 항상 3단계가 걸리는 알고리즘은 빅오로 어떻게 표현할까?
- O(3) 같지만, O(1)이다.
- 결국 데이터의 수를 극한으로 보내면, 어떻게 되느냐가 중요한듯 하다.
- 1000억개의 데이터를 찾을때 항상 3단계가 걸리는 알고리즘은 단계수가 변하지 않으니 상수로 O(1)이든 O(3)이든 중요하지 않으니 O(1)로 나타낸다.
- 빅 오표기법은 일반적으로 최악의 시나리오를 의미한다. 그래서 운좋게 한번에 찾더라도 O(N)으로 나타낼수도 있는 것

## 3.3 세 번째 유형의 알고리즘
- 이진검색의 시간복잡도는 O(logN)이다.
- 로가리즘이라는 수학적 개념을 이해해야 O(logN)인지 이해할 수 있다고 한다.
- 엥... 그런가 그냥 데이터의 수가 2배가 될때마다 1단계씩 늘어난다는 것 자체가 당연히 logN아닌가.. 너무 이걸 당연하게 받아들인건가?


## 3.4 로가리즘
- 복잡해보이지만, 결국은 로그의 정의와 같네


## 3.5 O(logN) 해석
- 컴퓨터 과학에서는 밑 2를 생략해서 그냥 logN이라고 한다고 한다.


## 3.6 실제 예제
- 리스트내의 모든 원소를 출력해야하기 때문에, 데이터의 수에 영향을 받을 수밖에 없고 그렇기 때문에 O(N)

# 4장. 빅 오로 코드 속도 올리기
- 빅오 표기법으로 알고리즘 간 성능을 비교할 수 있다.

## 4.1 버블 정렬
- 버블 정렬은 앞 뒤를 비교해가며 정렬하는 알고리즘

## 4.2 버블 정렬 실제로 해보기
- 각 루프마다 정렬되지 않은 값들 중 가장 큰 값이 올바른 위치로 가게 되고, 전체 루프를 다 돌면 정렬 완료
- 즉 O(n^2)

## 4.3 버블 정렬의 효율성
- 버블 정렬은 O(n^2)의 알고리즘이고, 이차시간이 걸린다고도 함.
