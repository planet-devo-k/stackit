# 8장. 스택과 큐로 간결한 코드 생성
## 9-1 스택
- 스택은 보통 배열로 구현하며, 위로 원소를 쌓는 자료구조이다.
- 중간에 원소를 뺄수는 없고, 위에서부터 원소를 뺄수있다.
- LIFO

## 9-2 추상 데이터 타입
- 스택을 구현하기 위해서는 대부분 내부적으로 배열을 사용한다.
- 내부적으로 LIFO 방식으로 동작하는 데이터 원소들의 리스트면 되기 때문에, 배열이든 링크드리스트든 스택을 구현할 수 있다.
- 그래서 스택은 추상 데이터 타입이다.

## 9-3 스택 다뤄보기
- 자바스크립트 린터같은 경우에 괄호가 제대로 닫혔는지 검사해야하는데 이때 스택이 유용하다.
- 스택으로 구현하면 복잡해보이는 괄호 검사기도 간단하게 만들 수 있다. 그런데, 스택의 내부 구현이 배열이라면 스택이 하는 일은 배열도 할 수 있다는 거고... 그렇다면 배열로 구현하면 되지 않을까?

## 9-4 제약을 갖는 데이터 구조의 중요성
- 제약을 갖는 배열이라는 말이 중요한데, 스택은 제약을 갖고 있기 때문에 잠재적인 버그를 막을 수 있다.
- LIFO라는 사고방식에 입각한 사고 모델을 제공하므로 린터와 갖은 비슷한 문제상황에서 금방 해결방법을 찾아낼 수 있다.... 이런 시각도 있구나
