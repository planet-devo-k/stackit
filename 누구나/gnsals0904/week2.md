# 2장. 알고리즘이 중요한 까닭
## 2.1 정렬된 배열
- 삽입 시, 적절한 위치를 찾아야하니까 검색이 선행되어야 한다.
- 앞에 삽입을 하든, 뒤에 삽입을 하든 성능은 비슷하다.
  - 음... 앞에 넣으면 검색을 적게하고 뒤로 shift 하는 연산이 많고
  - 뒤에 넣으면 검색을 많이하고 뒤로 shift 하는 연산이 적고
  - 사실 이진탐색을 한다고 하면 앞이나 뒤나 검색하는 수는 같고 shift하는건 달라질테니 앞에 원소를 삽입하는 상황이 더 안좋기는 할 것 같은데

## 2.2 정렬된 배열의 검색

## 2.3 이진 검색
- 이진 검색 내용과 같음.
- 정렬이 된 배열을 탐색할때, 업 다운으로 절반씩 무조건 줄여나갈 수 있으니 logN의 시간복잡도가 보장됨

## 2.4 이진 검색 대 선형 검색
- 그래프를 보니 직관적으로 성능 차이가 보인다.
