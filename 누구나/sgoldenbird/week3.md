# 3. 빅 오: 데이터가 N개일 때 몇 단계가 필요할까?

- 복잡하지 않을지라도 뭔가를 하는 코드는 모두 엄밀히 알고리즘, 즉 문제를 풀어나가는 절차다.
- N을 찾는 연습
  - N을 전달할 때 알고리즘에 몇 단계가 필요할까
- O(1) : 데이터가 N개일 때 항상 1단계만 필요하다. 원소가 몇개든 항상 한 단계면 된다. 데이터가 늘어나도 단계수는 증가하지 않는다. N이 얼마든 항상 상수 단계만 필요하다. 상수 시간을 갖는 알고리즘(constant time algorithm)이다.
- O(N) : 데이터가 N개일 때 N단계가 필요하다. 선형 시간을 갖는 알고리즘(linear time algorithm)이다.
- O(logN) : 데이터가 N개일 때 logN단계가 필요하다. 로그 시간의 시간 복잡도. 데이터가 두 배로 증가할 때마다 한 단계씩 늘어난다.
- O(N^2) : 데이터가 N개일 때 N의 제곱 만큼 단계가 증가. 이차 시간(quadratic time)을 갖는 알고리즘

## 빅 오의 본질: 데이터가 늘어날 때 알고리즘의 성능이(단계 수) 어떻게 바뀌는지

- 빅 오 표기법은 일반적으로 최악의 시나리오를 의미한다.

## 빅 오의 수학적 설명

빅 오를 함수 증가율의 상한값으로 설명하거나 함수 g(x)가 함수 f(x)보다 빠를 수 없을 때 g는 O(f)에 속한다고 말하기도 한다.

# 로가리즘(logarithm)

- 로그는 로가리즘의 줄임말이다.
- 로가리즘은 지수(exponent)와 역(inverse)의 관계다.
- 예) log2(8) = 3, 2^3 = 8
  - 2를 몇번 곱해야 8을 얻을 수 있는지
  - 몫이 1이 될 때까지 8을 2로 계속해서 나눌 때 등식에 얼마나 많은 2가 등장할지, 다시말해 1이 나올 때까지 8을 2로 몇번 나눠야 할지 8/2/2/2 = 1, 3번
- 참고 프로그래머스 [1로 만들기 문제](https://school.programmers.co.kr/learn/courses/30/lessons/181880)

## O(logN)

- 데이터 원소가 N개 일때, 알고리즘에 logN 단계가 걸린다는 의미. log8=3 이므로 이 알고리즘은 3 단계가 걸린다. 원소 8개를 절반으로 계속 나누면 원소가 하나 남을 때까지 3단계가 걸린다. 즉, O(logN)은 원소가 하나 될 때까지 데이터 원소를 계속해서 반으로 줄이는 만큼의 단계수가 걸린다는 뜻이다.
