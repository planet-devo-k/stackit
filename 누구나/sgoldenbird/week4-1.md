# 4. 빅 오로 속도 올리기 - 정렬 알고리즘

## 버블 정렬

Pass-through

1. Comparison: 배열 내에서 연속된 두 항목을 가리킨다. 첫번째 원소부터 시작
2. Swap: 두 항목의 정렬 순서가 뒤바뀌어 있으면 두 항목을 교환한다. 순서가 올바르다면 아무것도 하지 않는다.
3. Increment: 포인터를 오른쪽으로 한 셀씩 옮긴다. 1단계부터 3단계 반복.

교환이 일어나지 않는 pass-through가 생길 때까지 pass-through를 반복한다.

### 버블 정렬의 효율성: O(N^2)

버블 정렬 알고리즘은 두 가지 중요한 단계를 포함한다.

- 비교(comparison): 어느 쪽이 더 큰지 두 수 비교
- 교환(swap): 정렬하기 위해 두 수 교환

원소 N개가 있을 때,

- 비교: (N-1)+(N-2)+(N-3)...+1 번
- 교환: (N-1)+(N-2)+(N-3)...+1 번 (최악의 시나리오 비교 할때마다 교환)

데이터가 늘어날 수록 단계 수가 매우 급격히 증가. O(N^2)을 이차 시간(quadratic time)이라고 한다.

## 이차 문제 $$O(N^2)$$

- 루프 내에 다른 루프를 중첩하는 알고리즘은 대부분(항상은 아니다) O(N^2)이다. 중첩루프가 보이면 O(N^2) 알람이 머릿속에 울리기 시작해야 한다. O(N^2)은 상대적으로 느린 알고리즘이기 때문.
- 느린 알고리즘을 마주할 때는 시간을 들여 더 빠른 대안은 ㅇ벗을지 깊이 생각해보는 것이 좋다.

## 선형 해결법 $$O(N)$$

- 중첩 루프의 대안으로 선형 해결법을 사용할 수 있다. (p94)
  - existingNumbers 빈 배열 생성
  - array 각 숫자 확인
  - 숫자가 나올 때마다 existingNumbers에서 그 숫자에 해당하는 인덱스에 임의의 값 추가(책에서는 1)
  - 본질적으로 existingNumbers의 인덱스를 사용해 지금까지 array에서 어떤 숫자들이 나왔었는지 기억한다.
  - 이 인덱스의 값이 이미 1인지 확인
  - 1이면 중복 값 찾은 것. 바로 true 반환.
- 단, 위 방식은 이차 방식보다 메모리를 더 소비한다.
