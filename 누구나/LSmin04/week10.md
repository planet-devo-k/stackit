```python
def reverse(string)
    # 기저 조건: 문자 하나로 된 문자열
    return string[0] if string.length == 1

    return reverse(string[1, string.length - 1]) + string[0]
end
```

## 5. 애너그램(anagram) 생성

- 애너그램: 문자열 내 모든 문자들을 재배열한 문자열

### 1. 애너그램 생성의 효율성

- 길이가 N인 문자열은 애너그램을 N!개 생성한다.
- 빅 오 표기법: O(N!)
