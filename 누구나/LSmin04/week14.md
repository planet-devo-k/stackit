# 15장 이진 탐색 트리로 속도 향상

## 1. 트리

- 루트(root): 가장 상위 노드
- 부모와 자식
- 조상과 자손
- 레벨(level)
- 트리의 프로퍼티(property): 균형 잡힌 정도
    - 균형 트리: 좌우 하위 트리의 높이가 균형을 이루는 트리

## 2. 이진 탐색 트리

- 이진 트리는 각 노드에 자식 개수는 0, 1, 2 중 하나다
- 이진 **탐색** 트리는
    - 각 노드는 왼쪽 자식과 오른쪽 자식을 각각 최대 하나씩 가질 수 있다
    - 한 노드의 “왼쪽” 자손은 그 노드보다 작은 값만 포함할 수 있다. “오른쪽” 자손은 그 노드보다 큰 값만 포함할 수 있다

## 3. 검색

- 트리 검색은 반드시 **루트부터 시작**해야 한다

### 1. 이진 탐색 트리 검색의 효율성

- 균형 이진 탐색 트리: O(log N)

### 2. log(N) 레벨

- 균형 이진 탐색 트리의 레벨은 노드가 N개일 때 O(log N)이다

## 5. 삭제

### 1. 자식이 둘인 노드 삭제

- 자식이 둘인 노드를 삭제할 때 삭제된 노드를 **후속자 노드**로 대체한다
    - 후속자 노드: 삭제된 노드보다 큰 값 중 최솟값을 갖는 자식 노드

### 2. 후속자 노드 찾기

- 삭제된 값의 오른쪽 자식으로 이동한 뒤, 왼쪽 자식을 따라 내려가며 더 이상 왼쪽 자식이 없는 노드를 찾는다.

### 3. 오른쪽 자식이 있는 후속자 노드

- 후속자 노드를 삭제된 위치에 넣고, 후속자의 오른쪽 자식을 원래 부모의 왼쪽 자식으로 넣는다

### 4. 완전한 삭제 알고리즘

- 자식이 없으면 노드를 삭제한다
- 자식이 하나면 노드를 삭제하고 자식을 삭제된 위치에 넣는다
- 자식이 둘이면 후속자 노드(삭제할 노드보다 큰 값 중 최솟값)로 대체한다
- 후속자는 오른쪽 자식에서 시작해 왼쪽 자식을 따라 내려가며 찾는다
- 후속자에게 오른쪽 자식이 있으면 그 자식을 후속자의 원래 부모의 왼쪽 자식으로 연결한다

### 5. 코드 구현: 이진 탐색 트리 삭제

### 6. 이진 탐색 트리 삭제의 효율

- 검색 및 노드 연결 처리 ⇒ O(logN) (균형 이진 탐색 트리 기준)

## 6. 이진 탐색 트리 다뤄보기

- 검색, 삽입, 삭제에서 O(logN) 이므로 데이터를 자주 수정하는 경우에 효율적이다

## 7. 이진 탐색 트리 순회

- 모든 노드를 방문하므로 O(N)
