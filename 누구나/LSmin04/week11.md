## 2. 빅 오를 위한 작은 개선

- 앞선 예제에서 함수 호출 결과를 변수에 저장한다.
    - 기존의 함수 호출 자리를 변수로 대체한다.

## 3. 재귀의 효율성

- 첫 번째 함수는 O(2^N)이다.
- 개선된 함수는 O(N)이다.

## 4. 하위 문제 중첩

- 하위 문제: 동일한 문제를 작게 만들어 해결함으로써 어떤 문제를 풀 때 더 작은 문제를 말한다.
- 하위 문제 중첩되는 이유
    - 같은 하위 문제를 여러 번 계산하기 때문에 하위 문제가 중첩된다.
- 피보나치 예제는 O(2^N)으로 매우 느리다.

## 5. 메모이제이션을 통한 동적 프로그래밍

- 동적 프로그래밍: 하위 문제가 중첩되는 재귀 문제를 최적화하는 절차

#### 방법1 - 메모이제이션

- 메모이제이션(memoization): 하위 문제가 중첩될 때 재귀 호출을 감소시키는 기법
    - 먼저 계산한 함수 결과를 기억해 재귀 호출을 감소시킨다.
- 해시 테이블에 저장하고 나중에 쓸 수 있다.
    - 해시 테이블은 메모리 내 객체로 함수 호출 중에 수정하더라도 한 재귀 호출에서 다음 재귀 호출로 전달할 수 있다.

### 1. 메모이제이션 구현

- 빅 오는 O(N) 이다.
