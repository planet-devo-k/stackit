# 3. 배열 탐색
## 3-1 선형 탐색
- 데이터를 선형적으로 탐색하는 알고리즘
- 일반적으로 생각하는 방법

## 3-2 이진 탐색
- 배열에서 데이터를 탐색하는 방법
- 이미 정렬된 배열이라면, 절반씩 나누어서 탐색하면 탐색 시간을 획기적으로 줄일 수 있다는 아이디어로 탐색을 진행

# 4. 그래프
## 4-1 그래프란?
- 여기서 말하는 그래프는 이산수학에서의 그래프
- 노드(= 정점, vertex)와 간선(edge)로 이루어짐
  - 관계를 표현할 수 있음
- 가중 그래프
  - 가중치가 있는 그래프
  - 간선에 값(가중치)이 있음
  - 무게(weight), 비용(cost)를 붙이는 것이 컨벤션
- 방향이 있는 그래프
  - 특정 노드에서 특정 노드로 방향이 있는 경우를 표현하기 위한 그래프
    - 보통 방향이 있는 간선으로만 이동할 수 있음
    - 양방향, 단방향 그래프가 있음

## 4-2 너비 우선 탐색
- BFS
- 큐를 이용하여 구현
- 시작점으로부터 가까운 곳부터 탐색을 진행하기 때문에 너비 우선 탐색이며 큐를 사용함
- 폐로가 있는 그래프는 트리라고 한다.
  - 보통 폐로라고 하진 않고, 사이클이라고 표현함.
  - 사이클이 없는 그래프 == 트리

## 4-3 깊이 우선 탐색
- DFS
- 스택, 재귀의 구조를 사용함
- 스택을 사용하기 때문에, 늦게 들어가는 정점이 먼저 나옴.
- 그렇기 때문에 점점 퍼지는 탐색 형태가 아닌, 하나의 길을 우선적으로 depth를 높여가며 탐색하는 형태가 됨.
