# 2-1. 정렬이란?

## 숫자를 작은 순으로 나열하기

메일프로그램에 쌓인 이메일을 생각해볼떄, 수신 시간이나 보낸사람으로 정렬할 수 있음.
이는 메일 프로그램이 수신시간이나 보낸사람을 숫자로 여기고 작은 순으로 정렬해주는 것.
이처럼 숫자를 작은 순서(혹은 큰 순서)로 나열하고 싶은 다양한 경우를 생각해 볼 수 있는데,
여기서 활약하는 것이 정렬 알고리즘.

## 정렬이란?

입력으로 주어진 숫자를 작은 순으로 나열하는 것을 말함. 숫자가 작다면 사람이 수작업으로 간단히 정렬할 수 있지만,
숫자가 커질 수록 무척 힘들것. 이런 경우에는 효율이 좋은 알고리즘을 사용하는것이 중요함

## 다양한 정렬 알고리즘

중복이 있어도 알고리즘은 올바르게 동작

# 2-2. 버블 정렬

오른쪽에서 시작하여 왼쪽 방향으로 인접한 두 숫자를 비교하여 교체하는 작업을 반복. 오른쪽에서 왼쪽으로 숫자가
이동해 가는 모습이 물속에서 공기가 떠오르는 것과 비슷해 붙은 이름

1. 수열의 오른쪽 끝에 저울을 두고 좌우 숫자를 비교. 오른쪽 숫자가 더 작으면 왼쪽과 바꿈
2. 비교를 완료하면 저울을 한 칸 왼쪽으로 옮겨서 같은 방법으로 숫자를 비교.
3. 저울이 왼쪽 끝에 도착할 때까지 같은 작업을 반복
4. 저울을 오른쪽 끝으로 다시 옮기고 두번째 위치에 저울이 도착할 때까지 이전과 동일한 작업을 반복
5. 저울을 오른쪽 끝으로 옮기고 모든 숫자가 정렬될 때까지 같은 작업을 반복

# 2-3. 선택 정렬

'수열에서 최솟값을 찾아서 가장 왼쪽의 숫자와 교체'하는 작업을 반복하여 정렬. 수열에서 최솟값을
찾을 때는 선형 탐색을 사용

1. 수열을 선형탐색하여 최솟값을 찾는다
2. 최솟값을 가장 왼쪽에 있는 숫자와 교체하여 최솟값의 정렬을 마침. 최솟값이 이미 왼쪽 끝에 있으면 아무런 작업을 하지 않는다
3. 남은 숫자를 선형탐색하여 최솟값을 찾는다.
4. 찾은 최솟값을 두번째에 있는 값과 교체하여 두번쨰로 작은 숫자의 정렬을 마침
5. 모든 숫자가 정렬을 마칠 떄까지 같은 작업을 반복

# 2-4. 삽입 정렬

수열의 왼쪽부터 순서대로 정렬. 알고리즘의 진행에 따라 왼쪽에는 숫자가 점차 정렬되고 오른쪽에는 아직 확인하지 않는 숫자가
남음. 오른쪽의 미탐색 영역에서 숫자를 하나씩 꺼내 정렬이 끝난 영역의 적절한 위치에 삽입해 나가며 정렬을 완성

1. 왼쪽 끝의 숫자를 정렬이 끝난 것으로 간주하고 넘어감
2. 이어서 아직 정렬하지 않은 미탐색 영역에서 가장 왼쪽에 있는 숫자를 꺼내서 정렬이 완료된 영역의 숫자와
   차례로 비교. 왼쪽의 숫자가 크면 두 숫자를 바꿈. 이 작업을 자신보다 작은 숫자가 나타나거나 왼쪽 끝에 도달할 때까지 반복
3. 모든 숫자가 정렬될 때까지 같은 작업을 반복

# 2-5. 힙정렬

힙이라는 데이터를 사용하는 것이 특징

1. 힙에 모든 숫자를 삽입. 힙은 내림차순이 되도록 구성합니다
2. 힙에 저장된 숫자를 하나씩 꺼내 정렬합니다.
3. 먼저 뿌리(root)에 있는 숫자를 꺼내고 힙을 재구축.
4. 다시 뿌리에 있는 숫자를 꺼내서 오른쪽에서 두번째 칸에 두고 힙을 재구축
5. 이후 힙의 모든 데이터를 꺼낼 때까지 같은 작업을 반복

# 2-6. 병합 정렬

정렬할 수열을 거의 같은 길이의 수열 두개로 분할하고, 더 이상 분할할 수 없게 되면 그룹끼리 통합하기 시작함. 통합할 때는 정렬된 수열 두 개를 통합하여 하나로 정렬. 이러한 과정을 정렬된 수열이 하나가 될 때까지 반복

# 2-7. 퀵 정렬

기준이 되는 수를 수열 안에서 임의로 하나 선택하고, 피봇 이외의 수를 ‘피봇보다 작은 수’와 ‘피봇보다 큰 수’의 두 그룹으로 나누고, 이것을 다음과 같이 배치

```c
 [피봇보다 작은 수] < 피봇 < [피봇보다 큰 수]
```

이제 각 대괄호 안을 정렬하면 전체가 정렬됨. 대괄호 안을 정렬할 때도 다시 퀵 정렬을 사용
