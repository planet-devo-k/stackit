# 4-4. 벨먼-포드 알고리즘

> 그래프의 최단 경로를 찾는 알고리즘. 최단 경로 문제는 시작점과 끝점이 지정되어있고, 간선에 비용이 부여된 가중 그래프가 주어졌을 때, 시작저과 끝점까지의 경로 중 비용의 합이 가장 작은 것을 찾는 문제.

# 4-5. 다익스트라 알고리즘

> 이전 절에서 살펴본 벨먼-포드 알고리즘과 마찬가지로 그래프의 최단 경로를 구하는 알고리즘. 시작점에서 끝점에 이르는 경로 중에서 간선 비용의 합이 최소인 것을 찾음

# 4-6. A\* 알고리즘

그래프의 최단 경로 문제를 해결하는 알고리즘. 다익스트라 알고리즘을 발전시킨 것. 다익스트라 알고리즘은
시작점에서 각 정점에 이르는 최단경로를, 시작점에서 가까운 정점부터 결정. 그러다 보니 종점에서 멀어지는
방향에 있는 정점들의 최단 경로도 결정하게 되는데 이 계산은 결국 사용되지 않기 때문에 불필요.
A\*는 미리 추정 비용을 힌트로 설정하여 이 정보를 이용함으로써 불필요한 탐색을 생략하도록 개선되었음.

- 휴리스틱 비용 : 사람의 손으로 미리 설정한 추정비용. 사전에 알고 있는 정보를 바탕으로 적절한 추정비용을
  설정하여 힌트를 제공하면 더 효율적으로 탐색할 수 있음.
- 힌트같은 정보가 아예 없을 경우 A\*를 사용하지 않음
- 휴리스틱 비용과 실제 비용이 가까우면 가까울수록 검색 효율이 높음. 반대로 실제 비용과 동떨어진 값을 휴리스틱 비용으로
  사용하면 다익스트라 알고리즘보다 효율이 더 떨어질 수 있으며, 더 나아가 심하게 동떨어진 휴리스틱 비용을 사용하면 아예 정답을
  찾지 못할 수도 있음.

# 4-7. 크루스칼 알고리즘

그래프의 최소 신장 트리를 구하는 알고리즘. 간선에 비용이 있는 그래프에서 간선을 선택하여 모든 정점을 연결. 이때 선택한 간선비용
의 총합이 최소가 되어야 함

- 그리디(greedy)알고리즘: 각 시점에서 최선의 것을 선택하는 알고 리즘.

입력 그래프의 정점 수를 n, 간선 수를 m이라고 할때 알고리즘은 간선을 하나씩 살펴보기 때문에 m회 이내로 반복을 마침.
따라서 계산시간이 O(m)일것 같지만 그렇지 않음. 먼저 간선을 비용이 작은 순으로 살펴보기 위해서는 간선을
비용이 작은 순으로 정렬해야함. 이전 처리를 위해 O(m log m)의 계산 시간이 필요함.
또한 후보 간선을 정했을 떄 그 간선을 선택함으로써 폐로가 생기는지 여부를 확인해야함. 매번 폐로를 탐색하면
색하면 시간이 오래걸리지만 서로소 집합 데이터 구조라는 고도의 데이터 구조와 합집합 찾기 알고리즘을
사용하면 전체 계산시간은 O(m log m)이 됨. m >= n 이므로 전체 계산 시간은 O(m log m)

크루스칼 알고리즘과 마찬가지로 그래프의 최소 신장 트리를 구하는 알고리즘

# 4-9. 매칭 알고리즘

매칭 :정점 간에 짝을 지어주는 것
이분 그래프 : 정점이 왼쪽과 오른쪽이 나뉘어 있어 모든 간선이 오른쪽 정점과 왼쪽 정점을 연결하는 그래프.
매칭이란 어떤 사람에게도 두 개 이상의 작업을 할당하지 않고, 어떤 작업도 두 사람 이상에게 할당하지 않도록 하는 연결.

이번절의 시작에서 예로 든 작업 할당과 같이 매칭은 할당 문제를 풀 수 있어 무척 응용범위가 넓은 개념.
이번 절에서 알아본 매칭은 각 정점에 대해 하나의 매칭이 가능했지만 B-매칭이라는 보다 일반화한 매칭의 경우
각 정점에 값을 부여하여 그 횟수만큼 매칭이 가능
