# 6-1 클러스터링이란?

## 비슷한 것들 끼리 분류하기

클러스터링이란 많은 데이터가 주어졌을 때 비슷한 것끼리 같은 그룹으로 분류하는 것. 여기서 각 그룹을 클러스터라고 함

## 비슷한 것들을 정하는 기준

- 데이터간 거리 정의하기
  무엇을 기준으로 비슷하다고 할 지는 데이터에 따라 달라짐. 구체적으로는 데이터 간 거리를 정의해야함.
- 조건에 부합하는 알고리즘
  데이터 간 거리를 정의한 뒤에도 클러스터링 하는 방법은 다양함. 클러스터링 하는 목적에 따라 다양한 조건이 나올 수 있음

# 6-2 K-평균 알고리즘

클러스터링 알고리즘 중의 하나. 이 알고리즘은 클러스터의 개수를 사전에 정하고, 그 개수에 맞게 그룹을 나눔

1. 먼저 클러스터링을 수행하고 싶은 데이터를 준비하고 클러스터 개수를 정함.
2. 각 클러스터의 중심점으로 점 세개를 랜덤하게 배치
3. 각 데이터에 대해 세 중심점 중에서 가장 가까운 것을 계산
4. 각 데이터를 결정한 클러스터로 분류
5. 클러스터에 속한 데이터의 중심을 계산하여 해당 위치로 클러스터의 중심점을 이동
6. 가장 가까운 중심점을 재계싼하여 각 데이터의 클러스터를 재분류
7. 각 데이터를 클러스터로 분류하는 것과 클러스터의 중심점을 중심점이 수렴할 때까지 반복

- K-평균 알고리즘 외에도 계층적 군집화라는 알고리즘이 있는데, K-평균 알고리즘과 다르게 클러스터 개수를 미리 설정할 필요가 없음
- 클러스터를 합칠 때는 가장 가까운 두 클러스터를 결정하기 위해 클러스터 간 거리를 정의해야 함
  정의 방법으로는 최단 연결법, 최장 연결법, 평균 연결법 등의 알고리즘이 존재

# 7-1 데이터 압축과 부호화

## 데이터를 짧게 만드는 것이 압축

컴퓨터는 데이터를 0 또는 1이 나열된 이진수로 처리(디지털 데이터) 컴퓨터는 텍스트로 디지털 데이터로 처리.
아날로그에서 디지털로 변환하는 것처럼 데이터의 표현 방법을 변환하는 것을 부호화(인코드)라고 하며, 부호화한 후에 데이터 크기가 작아지는 것을 압축이라고 함

# 7-2 런 렝스 부호화

부호와 그것이 연속되는 횟수를 하나의 묶음으로 부호화.

1. 5X5 칸을 세 가지 색으로 칠한 이미지 부호화.
2. 먼저 세 가지 색에 대해 각각 Y(yellow), G(green), B(Blue)라는 문자를 할당
3. 도형의 왼쪽 상단을 시작으로 한 줄씩 Y,G,B 문자로 변환한 결과, 25개 문자로 부호화하고, 이 이미지를 런 렝스 부호화를 통해 더 짧은 문자수로 표현
4. 런 렝스 부호화는 부호와 그것이 연속하는 횟수를 한 묶음으로 부호화하는 방법. 예를 들어 YYYY가 있다면 Y4로 표현
5. 런 렝스 부호화를 사용하기에 좋은 데이터와 그렇지 않은 데이터가 있음

- 좋지 않은 데이터 : 연속성이 적은 데이터(텍스트).
- 좋은 데이터: 연속성이 큰 데이터(이미지)
  실제 컴퓨터에서는 텍스트도 이진수로 부호화하여 취급

# 7-3 유일 복호 가능 부호

하프만 코드는 JPEG 같은 이미지나 ZIP 같은 파일의 압축에 사용됨.

1. ABAABACD 라는 문자열을 네트워크를 통해 보내는 경우를 생각. 데이터는 0과 1의 이진수로 부호화하여 전송
2. 만약 ASCII 문자코드를 사용한다면 ASCII는 문자하나를 8비트로 표현하기 때문에 64비트 크기의 데이터가 만들어짐
3. 현재 문자열에서는 4개의 문자만 사용하고 있으므로 4개를 구분할 수 있도록 부호화 하면 됨
4. 문자 하나를 2개로 표현하는 부호화 규칙을 만들고, 규칙에 따라 부호화
5. 그 결과 데이터 크기가 16비트로 대폭 줄어듦
6. 문자열을 전달받은 쪽에서는 부호를 두 문자씩 구분하여 각각 규칙에 대조해 복원하면 원래 문자열을 얻을 수 있음.
7. 여기서 A와 B를 1비트로 표현하면 더 작게 부호화할 수 있음.
8. 규칙에 따라 부호화하면 데이터의 크기는 10비트로 줄어듦
9. 부호를 전달받은 쪽에서 부호를 복원하려면 변환규칙과 대조하여 복원하면 됨
10. 부호에 대해 하나로 유일하게 복호화 할 수 없는 것을 유일 복호 불가능이라고 함

# 8-6 하노이의 탑

## 게임규칙

A,B,C라는 세 기둥이 있고 기둥 A에 원반 다섯개가 놓여 있음. 원반 다섯 개를 순서를 유지한채 C로 옮기는 것이 규칙

- 이동조건

1. 원반은 한번에 한개만 옮길 수 있음
2. 작은 원반 위에 그보다 큰 원반을 놓을 수 없음

n개 원반의 하노이 탑 문제는 n-1개 원반의 하노이 탑을 푸는 방법을 이용하면되고, n-1개 원반의 하노이 탑 문제를 풀려면
n-2개 원반의 하노이 탑 문제를 푸는 방법을 이용. 이와 같이 알고리즘의 기술에 알고리즘 자신을 이용하는 사고방식을
재귀라고 함. 이 재귀적 사고방식은 다양한 알고리즘에 사용되며 이를 재귀적 알고리즘이라고 함.
