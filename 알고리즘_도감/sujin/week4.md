# 3-1. 선형 탐색

> 배열에서 데이터를 찾는 알고리즘. 이진 탐색과 달리 데이터가 순서 없이 나열된 경우에도 적용할 수 있음. 찾는 방식은 단순히 배열 앞쪽부터 순서대로 데이터를 조사. 데이터는 어떤 종류라도 상관없음

# 3-2. 이진 탐색

> 배열에서 데이터를 찾는 알고리즘. 선형 탐색과 달리 데이터가 정렬된 경우에만 적용할 수 있음. 찾으려는 데이터와 배열의 정중앙 데이터를 비교하면 중앙 기준으로 왼쪽에 있는지 오른쪽에 있는지 알 수 있음. 따라서 한번 비교해서 검색해야 할 범위를 절반으로 줄일 수 있음. 데이터를 찾거나 데이터가 없다는 것이 확실해질 때까지 이 방법을 반복.

- 계산시간은 $O(log n)$

# 4-1. 그래프란?

## 이산수학에서의 그래프

몇개의 정점이 간선으로 연결되어 있는 것

- 정점(노드): 원으로 그려진 것
- 간선: 정점과 정점을 이은 선분

## 다양한 것을 표현할 수 있는 그래프

- ex) 파티 참가자 간의 지인관계, 지하철 노선도, 컴퓨터 네트워크의 접속 관계

## 가중 그래프

- 간선에 값이 붙어있는 그래프. 이때 간선에 할당된 값을 무게 혹은 비용이라고 부름.
- 간선에 비용이 있으면 연결의 강도를 표현할 수 있음

## 방향성 그래프

- 간선에 방향을 부여한 그래프. 비대칭적 비용도 표현할 수 있음
- 무방향 그래프: 간선에 방향이 없는 경우

# 4-2. 너비 우선 탐색

> 시작점에서 간선을 따라가며 정점을 탐색하여 지정한 정점(목표)에 도달하는 것. 너비 우선 탐색은 시작점에서 가까운 정점부터 탐색

# 4-3. 깊이 우선 탐색

> 시작점에서 지정된 정점에 도달하는 것이 목표. 깊이 우선 탐색에서는 하나의 길을 선택해서 갈 수 있는 만큼 진행하다가 더 이상 진행 할 수 없으면 되돌아가서 다음 후보 경로를 탐색함.
