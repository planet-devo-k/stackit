# 6-1 클러스터링이란?
- 많은 데이터가 주어졌을 때 비슷한 것끼리 같은 그룹으로 분류하는 것을 말합니다. 여기서 각 그룹을 클러스터라고 합니다.
- 비슷한 것을 정의하는 법
  - 데이터 간 거리 정의하기
  - 조건에 부합하는 알고리즘
    - 알고리즘은 클러스터의 개수가 k가 되도록 클러스터링 수행
# 6-2 k-means 알고리즘
- 클러스터리 알고리즘의 하나
- 클러스터의 개수를 사전에 정의하고 그 개수에 맞게 그룹을 나눔
- 알고리즘 동작
  1. 데이터, 클러스터의 개수 준비하기
  2. 각 클러스터의 중심점으로 점 세 개를 랜덤하게 배치
  3. 각 데이터에 대해 세 중심점 중에서 가장 가까운 것을 계산
  4. 가장 가까운 것이 클러스터가 됨 -> 클러스터 3개 구성
  5. 클러스터의 중간 지점을 다시 중심점으로 잡고 3,4 반복
  6. 클러스터의 중간 지점이 변하지 않을 떄까지 반복 -> 데이터가 비슷한 것끼리 분류됨
# 8-1 유클리드
- 기존 최대공약수 구하는 알고리즘의 문제
  - 두 수를 소인수 분해하여 공통 소수로 부터 최대공약수를 구함
  - 하지만 두 수의 크기가 크면 소인수분해가 어려워짐
- 유클리드
  - 두 수의 최대공약수를 빠르게 구하는 알고리즘
  - 커다란 수를 작은 수로 나눈 나머지 구하기 (A mod B = C)
  - B를 C로 나누기
  - 나머지가 0이 될 때까지 반복 (C가 0이 될 때 B가 최대공약수)
- 실제 과정(1112,695의 최대공약수 구하기)
  1. 1112 % 695 = 417
  2. 695 % 417 = 218
  3. 417 % 218 = 139
  4. 218 % 139 = 0
  5. 139가 최대 공약수
# 8-2 소수 판별법
- 어떤 자연수가 소수인지 아닌지를 판별하는 방법
- 소수란?
  - 1과 자기 자신 이외에 약수를 가지지 않는 1보다 큰 자연수
  - ex ) 2,3,5,7,11,13 ----
- 소수 판별법의 종류
  - 2~n-1까지 반복문을 돌며 나누어 떨어지는 수가 있는지 확인
  - 페르마 테스트 (확률적 소수 판별법)
    - 어떠한 수에 소수로 거듭제곱한 수에 소수로 나누면 나머지가 어떠한 수가 됨 
    - (n^소수 mod 소수 = n)
  - 그러면 소수 판별법이 n^판별할 수 mod 판별한 수가 n이 나오면 판별이 true인가?

# 8-6 하노이의 탑
- 원반을 올기는 게임으로 재귀 알고리즘의 좋은 예
- 이동조건
  - 원반을 한 번에 한 개만 옮길 수 있음
  - 작은 원반 위에 그보다 큰 원반을 놓을 수 없음
- 실제 이동 (초기 값 : A,B,C | A(2,1) -> C)
  1. A의 1을 잠시 B에 옮김 (B:1)
  2. A의 2를 C로 옮김 (C:2)
  3. B의 1을 C로 옮김 (C:2,1)
- 실제 이동 (초기 값 : A,B,C | A(3,2,1) -> C)
  1. A의 1을 잠시 C에 옮김 (C:1)
  2. A의 2를 B로 옮김 (B:2)
  3. C의 1을 B로 옮김 (B:2,1)
  4. A의 3을 C로 옮김 (C:3)
  5. B의 1을 A로 옮김 (A:1)
  6. B의 2를 C로 옮김 (C:3,2)
  7. A의 1을 C로 옮김 (C:3,2,1)
