# 1.4 스택

> 스택은 데이터를 쌓아 올리고 위에서 부터 꺼내는 자료형입니다.

- push로 가장 위에 데이터를 넣고 pop으로 가장 위에 있는 요소를 꺼낼 수 있으며 이러한 방식을 후입 선출, LIFO라고 합니다.

# 1.5 큐

> 큐는 삽입 위치와 꺼내는 위치가 다른 자료형입니다.

- enqueue로 데이터를 쌓고 dequeue로 가장 오래된 데이터를 꺼낼 수 있으며 이러한 방식을 선입 선출, FIFO라고 합니다.

# 1.6 해시테이블

> 해시 테이블은 해시 함수를 활용해 만든 구조로, 데이터를 효율적으로 검색할 수 있습니다.

1. HashMap의 특징과 문제점

    - HashMap은 동기화가 보장되지 않는 non-synchronized 클래스로, 멀티 클래스 보단 단일 클래스에서 사용된다.
        - HashMap에서 동기화가 되어 있지 않기 때문에 데이터가 유실되거나, NullPointerException이 발생할 가능성이 있다.
    - 다른 일부 Map 구현체들과 달리 null 값과 null 키를 모두 허용

2. ConcurrentHashMap

    - HashMap의 동시성 문제를 해결하기 위해 등장한 Map 구현체
    - 내부적으로 lock을 사용해 데이터를 안전하게 보호
        1. 스레드 안정성
        2. 세그먼트 락
        3. 읽기-쓰기 분리

# 1.7 힙

> 힙은 완전 이진트리를 기반으로 하여 여러 값 중 최댓값 혹은 최솟값을 빠르게 찾아내기 위한 자료형입니다.

- 힙은 마지막 레벨을 제외한 모든 노드가 꽉 채워진 형태인 완전 이진 트리의 구조를 가집니다.
- 우선순위 큐를 구현하기 위해 사용됩니다.

# 1.8 이진 탐색 트리

- 이진 탐색 트리의 특징
    - 각 노드의 값은 왼쪽 가지에 있는 노드들의 값보다 크다
    - 각 노드의 값은 오른쪽 가지에 있는 노드들의 값보다 작다
    - 그러므로 최댓값은 가장 오른쪽 노드가 되고 최솟값도 가장 왼쪽 노드가 된다.
