# 2.1 정렬이란?

> 데이터를 특정 기준에 따라 순서대로 재배열하는 알고리즘

정렬 알고리즘{{1}}은 데이터를 특정 기준에 따라 재배열하여 탐색 및 관리를 효율적으로 만드는 컴퓨터 과학의 핵심 기술입니다. 각 알고리즘은 실행 시간, 메모리 사용량, 안정성(
중복 데이터의 상대적 순서 유지 여부) 등에 따라 뚜렷한 장단점을 가집니다.

| 알고리즘명     | 시간 복잡도             | 공간 복잡도       | 안정성 | 제자리 정렬 | 주요 특징                          |
|:----------|:-------------------|:-------------|:----|:-------|:-------------------------------|
| **버블 정렬** | $O(n^2)$           | $O(1)$       | O   | O      | 간단하지만 데이터가 많을 때 가장 느림          |
| **삽입 정렬** | $O(n^2)$ (평균)      | $O(1)$       | O   | O      | 작은 데이터나 거의 정렬된 상태에서 효율적        |
| **힙 정렬**  | $O(n \log n)$      | $O(1)$       | X   | O      | 일관된 성능을 보장하는 이진 힙 기반 알고리즘      |
| **병합 정렬** | $O(n \log n)$      | $O(n)$       | O   | X      | 분할 정복 방식, 추가 메모리 공간($O(n)$) 필요 |
| **퀵 정렬**  | $O(n \log n)$ (평균) | $O(n log n)$ | X   | O      | 캐시 효율성이 우수하여 실제 상황에서 가장 빠름     |

### 2.2 버블 정렬

- 버블 정렬은 인접한 두 원소를 비교하여 순서가 맞지 않으면 서로 교체하는 과정을 반복하며, 큰 원소가 점진적으로 끝으로 이동하는 방식입니다.
- 구현이 매우 단순하지만, 데이터의 양이 많아질수록 성능이 급격히 저하됩니다.

### 2.3 삽입 정렬

- 삽입 정렬은 배열을 정렬된 부분과 정렬되지 않은 부분으로 나누고, 정렬되지 않은 데이터를 정렬된 부분의 적절한 위치에 삽입하며 크기를 키워나가는 방식입니다.
- 데이터가 거의 정렬되어 있는 상태일 때 매우 효율적이며, 최선의 경우 $O(n)$의 성능을 보입니다.

### 2.5 힙 정렬

> 완전 이진 트리 구조를 활용하여 정렬을 수행하는 방식

- 최대 힙이나 최소 힙을 구축한 후 루트 노드를 반복적으로 추출하여 정렬된 배열을 완성합니다.
- 최악의 경우에도 $O(n \log n)$의 안정적인 성능을 보장하며, 추가적인 메모리 공간이 거의 필요 없는 제자리 정렬 방식입니다.

### 2.6 병합 정렬

> 분할 정복과 병합을 통한 정렬

- 병합 정렬은 분할 정복을 사용하여 리스트를 절반으로 나눈 뒤, 각각 정렬하고 다시 합치는 재귀적 알고리즘입니다.
- 데이터의 원래 순서가 유지되는 정렬이며, 데이터의 크기가 커져도 성능이 일정하게 유지됩니다.
- 모든 상황에서 $O(n \log n)$의 시간 복잡도를 가지지만, 병합 과정에서 추가적인 메모리 공간이 필요합니다.

### 2.7 퀵 정렬

퀵 정렬은 특정 원소인 피벗(Pivot)을 기준으로 작은 값은 왼쪽, 큰 값은 오른쪽으로 나누어 분할 정복하는 방식입니다.
