**PR**

- 매주 **일요일 스터디 시작 1시간 전**까지 `main` 브랜치로 PR을 제출합니다.

**Deposit & Penalty**

- 세션이 시작된 이후에는 개인 사정으로 인한 중도 하차를 허용하지 않으며, 예외는 두지 않습니다.

- 보증금: 인당 30,000원
- 관리: 토스(Toss) 공동 모임통장
- 패널티
  - 결석, 10분이상 지각 시 -1,000원
  - PR 기한 내 미제출 시 -1,000원
- 정산
  - 정산은 세션 마지막 날 진행합니다.
  - 모인 패널티는 1/n로 나누어 가집니다.
  - 모임통장에서 발생한 이자 및 정산 시 발생하는 1,000원 단위 미만의 잔돈은 커뮤니티(Planet Devo K) 운영비로 귀속됩니다.
