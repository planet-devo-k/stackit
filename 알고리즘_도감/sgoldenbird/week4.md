# 배열 탐색 

- 배열에서 데이터를 탐색하는 알고리즘 
- 검색과 추가 중 어떤 작업을 빈번하게 하는지 고려해서 적합한 알고리즘 선택 
  - 선형탐색: 데이터 추가 good (단순히 마지막에 넣기만 하면 됨)
  - 이진탐색: 데이터 검색 good (추가는 정확한 위치에 해야함. 이진탐색을 하려면 데이터가 항상 정렬돼있어야하므로)

## 3.1 선형 탐색 $$O(n)$$
- 배열의 앞에서부터 순서대로 데이터를 확인 

## 3.2 이진 탐색 $$O(log n)$$
- 데이터가 정렬된 경우에만 적용 
- 배열의 가운데 있는 데이터와 대상 데이터를 비교 → 데이터가 정중앙보다 오른쪽에 있는지 왼쪽에 있는지 알 수 있다. 
- 한번의 비교로 탐색해야할 범위를 반으로 줄인다. 
- n개의 데이터를 매번 반으로 나누는 작업을 log n 회 반복하면 데이터는 한개가 된다. <br/>
→ 반으로 줄이는 작업을 log n번 반복하면 데이터를 찾을 수 있다. 
$$N \times \left(\frac{1}{2}\right)^{\log_2 N} = 1$$


# 그래프 탐색 

- 특정 정점에서 출발해 간선을 통해 이동해가며 대상 정점을 찾는 것
- 그래프를 탐색하는 알고리즘은 탐색 순서에 따라 너비 우선 탐색과 깊이 우선 탐색이 있다. 즉, 다음에 어떤 정점을 선택하는가의 차이 
- 최단 경로 문제는 두 정점을 연결하는 경로 중 간선의 가중치 합계가 가장 작은 것을 찾는 문제  

## 이산수학 (Discrete Mathematics)
- 연속적이지 않고 셀 수 있는, 서로 떨어진 대상을 연구하는 수학의 한 분야 (소수, 정수, 그래프, 논리연산)
- 컴퓨터가 모든 데이터를 0과 1 이라는 이산적인 디지털 신호로 처리하기 때문에 이산수학은 현대 컴퓨터 과학의 근간
- cf. 미적분학: 실수처럼 끊김없이 이어지는 대상을 다루는 수학의 한 분야 

## 4.1 그래프란?

### 이산수학에서의 그래프 
- node: 정점
- link: 간선 (정점과 정점을 연결하는 선)

### 가중 그래프 (Weighted Graph)
- 간선에 가중치를 부여한 그래프 
- cost: 가중치 (시간, 비용 등)
- link에 cost가 없을때는 두 node는 연결돼있거나 연결돼 있지 않거나 둘 중 하나
- ※ 정점에 가중치가 붙는 경우도 있다. 

### 방향성 그래프 (Directed Graph)
- link에 방향 부여. 방향성 그래프를 사용하면 비대칭 가중치(b → c, c → b 각 방향 코스트가 다른)도 표현할 수 있다.  
- 방향성 그래프에도 비방향성 그래프처럼 링크에 가중치 부여할 수 있다. 


### 그래프를 사용하면 무엇이 편리한가
- link 들 중 가중치의 합이 가장 작은 경로를 찾을 수 있다. 등 


## 4.2 너비 우선 탐색 (Breadth-First Search)
- 노드를 탐색할때 시작점에 가까운 노드부터 너비를 넓혀가며 탐색하는 방식 
- 선택 기준: 가장 먼저 후보가 된 정점. 시작점에 가까운 정점이 빨리 후보가 되므로 시작점에서 가까운 것부터 탐색. 같은 시점에 후보가 된 정점은 어느것을 선택하든 상관없다. 
- 큐 사용. FIFO 구조로 관리
- p86 [B, C, D, E, F]
- 폐로가 존재하는 경우도 같은 방법으로 탐색. 
  - ※ 폐로: 시작점과 종점이 같은 경로. 
  - 트리(tree): 폐로가 없이 연결된 그래프

## 4.3 깊이 우선 탐색 (Depth-First Search)
- 하나의 길을 끝까지 따라가며 더 이상 진행할 수 없는 곳에 다다르면 다음 후보가 되는 길을 따라간다. 
- 선택 기준: 가장 최근에(가장 늦게) 후보가 된 정점. 같은 시점에 후보가 된 정점은 어느것을 선택하든 상관없다. 
- 스택 사용. LIFO 
- 백트래킹: 메모리에서 지우며 되돌아 가는 것. LIFO인 스택에서만 나오는 개념
  - cf. BFS는 백트래킹이 아니다. (막다른 길을 만나 뒤로 back하는 과정이 없다. 묵묵히 전진할 뿐)
- p91 A [D, C, B] → B [D, C, F, E] → E [D, C, F, K] → K [D, C, F] → BACK to F [D, C]
