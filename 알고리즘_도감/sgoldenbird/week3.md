# 2.1 정렬이란?

- 같은 시간 복잡도로 분류되도 실제 실행 속도에서는 차이 → 교체 횟수 다르기 때문 ⇒ 연산의 종류에 따라 실제 성능이 달라질 수 있다.

# 2.2 버블 정렬 $$O(n^2)$$ 
- (오른쪽부터 왼쪽 방향으로) 인접한 두개의 숫자를 비교해서 교환 
- `비교` $$O(n^2)$$ (인접 요소 비교: 무언가를 찾아내는 탐색이 아님) 
  - 입력 데이터의 순서와 상관없이 일정 
  $$
  n-1 + n-2 + n-3 + ... + 1 = \frac{n(n-1)}{2} = O(n^2)
  $$
- `교환` $$O(n^2)$$ (최악의 경우: 모든 요소가 역순으로 정렬되어 있을 때, 매 비교마다 교환이 일어남) 
  $$
  n-1 + n-2 + n-3 + ... + 1 = \frac{n(n-1)}{2} = O(n^2)
  $$
- 전체 $$O(n^2)$$ (비교와 교환이 모두 O(n^2) 이므로, 전체 시간 복잡도는 O(n^2)입니다.)

# 2.3 선택 정렬 $$O(n^2)$$ 
- 최소값을 검색해서 왼쪽 끝에 있는 숫자와 교체하는 작업 반복
- `비교` $$O(n^2)$$ (최소값을 찾는 과정: 선형 탐색으로 모든 요소를 비교) 
  - 첫 번째 요소를 찾을 때 n-1번, 두 번째 요소를 찾을 때 n-2번, ... 마지막 요소를 찾을 때 1번 비교가 필요합니다. 
  $$
  n-1 + n-2 + n-3 + ... + 1 = \frac{n(n-1)}{2} = O(n^2)
  $$
  - 선형탐색: 처음부터 끝까지 순차적으로 하나씩 확인하며 원하는 조건을 만족하는 값을 찾는다. 찾으려는 값을 발견하면 즉시 탐색을 종료한다. 
- `교환` $$O(n)$$ 
  - 최소값을 찾은 후, 해당 요소와 현재 위치의 요소를 교환하는 작업
  - 최악의 경우, 매번 교환이 일어날 수 있지만O(n), 일반적으로는 O(1)입니다. 

# 2.4 삽입 정렬 $$O(n^2)$$ 
- (왼쪽부터) 순서대로 좌측에는 정렬이 끝난 숫자, 우측에는 아직 정렬이 안된 숫자들이 존재
- 첫라운드는 바로 졸료 (왼쪽 숫자 하나를 정렬된 영역으로 간주)
- `비교` $$O(n^2)$$ (선형 탐색. 목표를 찾는 순간 탐색 멈춤)
  - 미탐색 영역(우측)에서 왼쪽 끝에있는 숫자를 하나씩 꺼내서 정렬된 영역(좌측)에 삽입하는 방식
  - 첫 번째 요소를 삽입할 때 0번 비교, 두 번째 요소를 삽입할 때 1번 비교, ... 마지막 요소를 삽입할 때 n-1번 비교가 필요합니다. 
  $$
  0 + 1 + 2 + ... + (n-1) = \frac{n(n-1)}{2} = O(n^2)
  $$
- `교환` $$O(n^2)$$ 
  - 삽입하려는 숫자가 왼쪽의 숫자가 크면 두 개의 위치를 바꿉니다. 이 작업을 자신보다 작은 숫자가 나타나거나 왼쪽 끝에 도달할때까지 반복  
  $$
  0 + 1 + 2 + ... + (n-1) = \frac{n(n-1)}{2} = O(n^2)
  $$
- 버블 정렬과의 차이 → 비교를 언제 멈추느냐  
  - 삽입 정렬은 자리를 찾는 순간 비교를 멈춤 
  - 3, 5, 4, 7 예제에서 만약 3 앞에도 숫자들이 더 있었다면, 4를 5와 비교하고 그 다음 3과 비교했을 때 4가 3보다 크다는 것을 확인한 순간 삽입정렬은 비교를 즉시 중간. 3보다 앞에있으면 이미 3보다 작은것이기 때문. <br/>
  반면 버블정렬은 입력데이터의 순사와 상관없이 비교횟수가 항상 일정 

# 2.5 힙 정렬 O(n log n)  
- max heap) 부모가 자식보다 크기만 하면 됨. 우측 말미부터 루트와 교체 
- e.g. 토너먼트  
  - 1등 → log n (루트에 새로 올라온 노드가 다시 맨 아래 바닥까지 내려가야 하는 최악의 경우)
  - 2등 → log n 
  - 3등 → log n ... 
- `힙에 저장` O(n log n)
- `힙 재구축` O(log n)
- `힙이 완성된 후 정렬` O(n log n)

# 2.6 병합 정렬 O(n log n)  
- 재귀를 사용한 분할병합법
- 두개의 수열로 분할 
  - 병합 정렬에서 숫자를 분할해 갈때는 계산 시간이 걸리지 않는다. (처음 부터 분할된 상태라고 생각해도 좋다)
- 더이상 분할되지 않는 상태(각 그룹이 한개의 숫자가 된 경우)에 이르면 그룹들을 병합 → 정렬이 끝난 하나의 수열
  - [4,6] + [3,7] 여러 숫자를 포함하고 있는 그룹을 병합할때는 선두의 숫자를 비교해 작은 숫자를 이동
- `비교`: O(n-1)
- `병합`: O(n) 위로 올리는 과정 * O(log n) 층수 

# 2.7 퀵 정렬 O(n log n) 또는 O(n^2)
- 분할병합법의 일종, 재귀를 사용한 분할병합법 
  - 재귀: 알고리즘의 내부에 알고리즘 자신을 적용하는 것 
- 기준이 되는 수 pivot을 임의로 하나 선택
- 피봇보다 작은 수 < 피봇 < 피봇보다 큰 수 : pivot 이외의 수를 피봇보다 작은 그룹, 큰 그룹으로 나누고 배치
- 각 그룹에서의 정렬도 같은 방식으로 진행. 좌우에 숫자가 하나밖에 없으면 작업 완료   
- `분할`: O(log n) 또는 O(n) (매번 최소값이 피봇으로 선택되면 모든 숫자가 오른쪽으로 가기 때문에 선택정렬과 같은 처리가 됨)
- `비교`: O(n) 각 층에서 비교
